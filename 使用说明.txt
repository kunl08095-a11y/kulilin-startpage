KULILIN 起始页 / 新标签页
==========================

一、把新标签页换成它（扩展）
  1. 地址栏打开 chrome://extensions
  2. 右上角开启「开发者模式」
  3. 点「加载已解压的扩展程序」
  4. 选择本文件夹（KULILIN）
  5. 按 Ctrl+T 验证

  更新过页面后：在 chrome://extensions 里点本扩展的刷新按钮，
  再重新打开新标签页。扩展卸载后重新加载本文件夹即可。

二、把启动页 / 主页换成它
  地址栏打开 chrome://settings/onStartup
  选「打开特定网页或一组网页」，添加：
  file:///home/kulilin/Documents/KULILIN/index.html

  想让启动页和新标签页共用同一份快捷网站数据，
  启动时选「打开新标签页」更简单。

三、快捷网站 dock
  - 搜索框下方是一条黑线（没有网站时是黑点）；
    收起时线长跟随图标数量：一个图标 82、两个 126、三个 170，
    超过三个也保持 170，不会越加越长；靠近时线长连续增长，
    贴住时覆盖整排图标
  - 鼠标靠近时，黑线按距离逐渐下沉：
    约 160px 内开始下沉，约 80px 内沉到底（50px）
  - 线沉下去的同时，图标从横线里面冒出来：一冒头就沿着整条横线铺开，
    图标排的左右两端始终和线对齐；越靠近长得越大，排宽和线一起撑到
    最终宽度，间距随之收窄；缩放跟鼠标位置相关，离鼠标最近的那个最大，
    左右邻居依次变小
  - 「+」和普通图标走同一套动画：一起长出来、一起被放大、一起让位
  - 悬停放大：鼠标下的图标会放大约 1.4 倍，左右邻居被推开，间距保持 6px；
    鼠标还在图标旁边的空白处时就已经开始放大；放大中心和整排抬起/落回
    都会慢半拍（阻尼），鼠标急停或甩动时动画自然减速收尾
  - 下面的横条跟着变宽，两端对称伸缩（阻尼跟手，不会瞬间跳），移开后回落
  - 出现、收回、横线伸缩、整排抬起/落回都走阻尼；鼠标停下后会自然
    减速收敛，不会硬切
  - 排序：按住图标在 dock 内左右拖动，其他图标会让位，松手落位
  - 移除：按住图标拖出 dock（图标会变淡），松手即移除；
    6 秒内可以点「撤销」找回。右键图标，或选中后按 Delete 也可以。
  - 点「+」时横线自己长成胶囊形输入框（不是另盖一层），
    提交或按 Esc、点空白处再缩回成线
  - 图标会联网查找：站点自己的 favicon、国内图标服务、
    faviconextractor 三个来源自动兜底，失败则显示首字母
  - 最多 7 个
  - 数据保存在 chrome.storage（扩展环境），关掉浏览器不会丢；
    用 file:// 直接打开时退回 localStorage
  - 触屏：点一下横线展开并固定，点空白处收起

四、文件说明
  index.html     页面
  app.js         搜索、搜索引擎切换、快捷网站逻辑
  url.js         地址识别（中文域名、IP、localhost 等）
  manifest.json  扩展清单
  icons/         扩展图标
  test/          地址识别的测试

直接双击 index.html 也能当普通网页用。

五、测试
  node --test test/
  （需要 Node 18 以上，只测地址识别，不用装依赖）
