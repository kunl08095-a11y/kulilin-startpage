# KULILIN 起始页

[English](README.en.md) | 中文

一个极简的 Chrome 新标签页：搜索，加上最多 7 个快捷网站。当前版本是 1.6.6。

个人网站：[kulilin.com](https://kulilin.com)

## 功能

- 搜索框可切换搜索引擎（Google、Bing、百度、DuckDuckGo、知乎、GitHub）
- 搜索框下方有一条快捷网站横线：鼠标靠近时展开图标，点击「+」添加，最多 7 个
- 按住图标可左右排序；拖出横线、右键或按 Delete 可移除，6 秒内可撤销
- 触屏可点一下横线展开，点空白处或按 Esc 收起
- 当作扩展使用时，数据保存在本地 `chrome.storage`，关掉浏览器也不会丢失

## 安装（推荐：作为 Chrome 扩展）

1. 下载或克隆本仓库
2. 在 Chrome 地址栏打开 `chrome://extensions`
3. 打开右上角「开发者模式」
4. 点击「加载已解压的扩展程序」，选择本仓库文件夹
5. 按 `Ctrl+T` 打开新标签页，即可看到起始页

以后如果更新了文件，到扩展页点击本扩展的刷新按钮，再重新打开新标签页即可。

### 其他用法

- 也可以在 `chrome://settings/onStartup` 中选择「打开特定网页或一组网页」，添加本目录的 `index.html`，把它当作启动页。若希望启动页和新标签页共用同一套快捷网站，把启动时的选项改成「打开新标签页」即可。
- 直接双击 `index.html` 也能当普通网页使用（这时数据会改存到 `localStorage`）。

## 使用

- 在搜索框里输入内容，并切换要用的搜索引擎
- 把鼠标移到搜索框下方的横线附近，即可展开快捷网站
- 点击「+」，输入网址或名称来添加网站
- 按住图标拖动可以排序；把它拖出横线即可删除

更详细的交互说明见仓库里的 [使用说明.txt](使用说明.txt)。

## 隐私

本扩展不会把你的搜索记录或快捷网站上传到开发者的服务器。设置和快捷网站只保存在你的电脑上（扩展环境用 `chrome.storage`，直接打开文件时用 `localStorage`）。

添加快捷网站时，扩展可能会向该网站以及第三方图标服务（如 favicon.im、favicon.cccyun.cc）请求站点图标，找到后会缓存在本地，之后不再重复请求。本扩展不执行远程代码。
